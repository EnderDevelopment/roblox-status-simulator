# Roblox Cosmetic Verified Badge Script

This Roblox script is a client-side cosmetic badge script for Roblox Studio that displays a game-only “VERIFIED” label above the local player’s character. It does not verify a Roblox account, change account status, or grant Roblox platform privileges.

## Install

1. Open your experience in Roblox Studio.
2. In the Explorer, locate `StarterPlayer > StarterPlayerScripts`.
3. Insert a `LocalScript`.
4. Copy the contents of `FakeVerifiedBadge.client.lua` into the LocalScript.
5. Save and run the experience.

## Use

1. Start the experience in Roblox Studio.
2. The badge appears above the local player’s character after the character loads.
3. Reset the character or respawn to confirm that the badge is recreated automatically.
4. Edit the `badgeText` and `badgeColor` values in the script to customize the displayed text and color.

The badge is visible only to the client running the LocalScript. It is removed and recreated when the character respawns.
